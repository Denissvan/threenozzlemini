# 三吸嘴保留全部生产功能

用户已明确要求保留全部原生产功能。本次在既定三嘴交换主路径中恢复各功能的原触发条件、数据绑定、人工确认和失败处理；不以删除检查或禁止启动代替适配。

1. 扫码：按指定嘴接入上/下相机码、附加码、马达码、料盘防呆及OvenCheck相关流程，保持模组和源盘身份。
2. 回检：旧件取前回检、新件放后工站码和放偏检查；检查失败的2222/RETRY按原重新上下料语义处理。必须在治具放行前完成所有工站动作。
3. 模式：GRR、点检、自动点检、单嘴选择、清料转换遵循原穴位与循环语义。特殊模式可缩小并行窗口，但不能丢功能。
4. 接触横移：保留原偏移参数限幅与双臂避让，在指定嘴作用域内允许已限定的局部动作；其余嘴必须抬起，禁止扩大成通用低Z横移豁免。
5. 集成：逐项消除已实际适配的临时门禁，旧功能逐项追踪到原方法或等价新路径。运行真实源码假硬件回归、编译、审查；不连接设备。

硬件映射与机台标定门禁维持已确认方案。物理安全区域和真实节拍仍由现场验收确定。
