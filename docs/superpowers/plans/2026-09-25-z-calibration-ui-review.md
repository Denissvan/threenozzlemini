# Z标定UI小幅适配实施计划

用户要求先根据现有UI小幅修改后审核。本阶段只交付可操作审核界面，不启用新的生产补偿或自动探测。

- 保留FrProduct工装参数区域三按钮的位置，分别打开臂1、臂2和补偿管理窗口，替换旧双嘴测高入口。
- 增加小型WinForms窗口：两臂选择、固定基准、三嘴测量值录入、候选补偿、读取当前已回零轴Z、确认保存草稿/放弃。

自动有界真空测高、重复性校验、补偿投入生产及示教反向换算，留待用户审核界面后实施；不以本次UI变更宣称整套标定已完成。
