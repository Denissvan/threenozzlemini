## 二、原标定方案评价及重要纠正

### 1. 原软件确实按“每臂共用 Z、两嘴相反方向”组织

`myfunc.cs:188–198` 中同臂两个 XT 构造时接同一 AXIS_UDL*_Z、不同 U。`XT.cs:883、959、1509` 及 `XtOfsAdj.cs:286–295、512–534` 通过嘴编号或对象决定 Z 正负。

这能确认软件的共轴、反向假设；仅凭代码不能确认机械连杆的具体形状。

### 2. 旧测高是测量工具，不是已经接入生产的高度补偿系统

`FrProduct.cs:1184–1234、1421–1467` 调用 `CaliZrefWLByZK`，传 `(-10000,-10000)`，即在当前 XY 测量；组合测高不是自动逐嘴找同一小基准点。函数粗寻后重复细测，默认三次，返回平均值。组合页显示 `(zref[0]+zref[1])/2`，该表达式基于有符号的两嘴读数，不能沿用为三独立 Z 的高度差算法。

这些调用没有把测量值写入持久补偿，也没有自动修改料盘/工装 Z。不能用“原 UI 有测高”来证明原程序已有每嘴 Z 补偿。

原 `MovAndChkSensor` 中越界/退出结果可能被后续运动或传感器结果覆盖；因此新增页不能简单复用旧函数并改成三次循环。新测量服务需要明确探测边界、运动返回值、稳定触发和重复性判断。此处只讨论测量本身，不扩展异常恢复功能。

### 3. 工艺保存了 Z，不代表每个学习入口都真正采到了 Z

- `WsModuelDef.cs:406–428` 的多类学习直接读取机械臂共用 Z。
- `FrProduct.cs:887–907` 的 `TrayCfgGetPos` 将 `ax_z` 留为 null（赋值被注释），最终 Z 写为 0。这是当前所读原版的明确实现，不能再笼统说“料盘学习就是记录当前 Z”。
- `FrProduct.cs:596–655` 跨臂计算使用另一臂的点位与视觉基准换算 XY，同时保留其高度值；独立建立两臂 B 后，不能默认另一臂的工艺 Z 可以直接复制。
- `XtOfsAdj` 中试放/下降按旧嘴编号选择正负，必须与新高度换算一起适配。

### 4. 不得对所有 `.z` 字段统一加补偿

- 料盘/工装取放高度属于嘴接触工艺坐标，才应用嘴补偿。
- 轴调试显示的是控制卡实际轴坐标，不加补偿。
- `NpointCail.cs:231、263` 的 `st_pos_up_cap.z` 被作为料盘 X 轴位置传给运动函数，不是嘴高度。
- `RotAndFly.cs:227、237` 的 `st_rol.z` 被保存/显示为旋转标定误差，不是嘴高度。
- 纯相机 XY 定位不能因为结构体里含 Z 就触发嘴下降。

### 5. 原有页面空间决定不能套用上一张整页示例

- 产品视觉页保留上部图像，操作区约占 36%；XtOfsAdj 的 Designer 宿主为 882×302。
- 系统校准页同样是上图像、下操作区，下部约占 35%；NpointCail 的设计宿主为 876×306。
- 工装参数组为 295×335，测高按钮各 89×42，组里还放着其他工装参数。
- 因此三次数据明细、六嘴结果、示教参数、操作按钮不能同时挤进一个原有小区块。滚动只能用于缩小窗口的兜底，不能作为正常操作布局。

## 三、方案比较与推荐

1. 只保留工装测高弹窗：改动少，但难以复用主界面点动/图像，仍容易与其他标定割裂。
2. **推荐：在原系统校准区域新增“吸嘴 Z 基准”页，保留原工装三按钮作为导航快捷入口。** 利用现有上下图像/操作区布局，分标签展示测高与设置；其余页面小幅适配六嘴和坐标语义。
3. 重建统一全屏标定向导：可重排所有内容，但改动范围大，会改变既有操作习惯，本次不推荐。

推荐方案不新建第二套视觉标定、不将所有功能搬入新窗、不在标定区增加物料对账。

## 四、新 UI 配套设计

### A. 系统→系统校准→吸嘴 Z 基准（新增一个页）

沿用现有上方图像区和下方操作区。下方按约 876×306 的可用区域设计，字号约 11–12pt，主要按钮约 36px 高；最终用实际 WinForms 控件校验 100%/125%/150% 缩放和宿主尺寸。

下方内部用“测高 / 基准点设置 / 测量明细”三个页，避免堆叠全部字段。

测高页草图：

```text
机械臂 [臂1 v]  模式：首次建立/重标   固定 B：未建立/xx.xxx
吸嘴       接触均值       极差       已存补偿       候选补偿       状态
N1         ...           ...        ...            ...            ...
N2         ...           ...        ...            ...            ...
N3         ...           ...        ...            ...            ...
[测量当前嘴] [依次测量三嘴] [保存本臂结果] [放弃本次结果]
当前选择：臂1/N2；数据单位 mm；补偿尚未保存/已保存
```

不并排展示两臂六嘴：切臂后显示对应三嘴，基准与未保存结果按臂隔离。首次保存需要三嘴合格；后续可只重标所选嘴。原三按钮改为“臂1标定 / 臂2标定 / 结果查看”，跳到同一页并选好臂，不再各有一套代码。

基准点设置页：

- 按臂显示三行：N1/N2/N3、对准基准面的机械轴 X/Y、标定 U、接近高度、探测终点、学习/定位。
- 三嘴接触同一物理基准面，但由于嘴有间距，对应的机械臂轴 X/Y 不一定相同。首次建议分别人工示教三嘴测量位置，不把未完成的视觉旋转中心当作 Z 标定前置条件。
- 已有可靠嘴间 XY 偏移后可以计算初值，但需逐嘴验证，不能把一组机械 XY 原样给三嘴使用。
- 接近高度/探测终点明确标注“本嘴轴坐标或归一化行程”，不宣称是固定 B；固定 B 由接触实测建立。
- 探测速度、重复次数、极差上限收在本页参数区。范围由实际机构确认，示例图中的 20/27mm 等数值不得作为默认设备参数。

测量明细页：每嘴三次读数、均值、极差、时间、所用基准点；只用于追溯，不挤占日常操作页。

### B. 主界面点动与轴参数

- 主界面保留两臂工具条形式；每臂增加嘴选择 N1/N2/N3，现有 Z+/Z−、U+/U−跟随选中嘴，X/Y仍属于臂。
- 标定页与点动区显式显示同一臂/嘴。若选中对象不一致，先要求明确选中，不悄悄改动其他页面的全局对象。
- 点动区显示实际 Z/U 和轴名；标定页结果显示归一化接触高度；两者不能同名为一个“Z”。
- 运行页坐标摘要同样覆盖三组 Z/U，可采用选臂后三行小表，避免仍用共用Z显示让审核人员误判当前嘴位置。
- 系统轴参数仍负责零点、轴号等硬件配置；标定保存不调整回零偏移。保留现有权限机制。

### C. 产品→视觉→放置检查

- 保留图像、轮廓、上下拍照、计算偏差、保存、试放、真空等原操作和布局。
- 原四个嘴按钮区域改为“机械臂 + 本臂嘴”两级选择或单个六嘴列表；与已有实际可用面积匹配，不加异常对账按钮。
- Z输入明确改名“工艺高度”；紧邻以只读方式显示“本嘴补偿 / 目标轴Z”，紧凑显示，不增加六行表格。
- 试放、试取、上下 Z 使用与生产同一换算入口；保存仍只保存产品视觉偏差，不兼任系统 Z 标定保存。
- 取料/放料模式仍分开维护 XY/角度偏差；N3需要独立识别模板与实际标定，不能复制 N1数值当作完成。

### D. 产品→料盘、工装

- 保留原盘类型、工站、机械臂、三点/阵列/数据表，以及“学习、定位、保存”等按钮。
- 第一版明确固定“示教基准嘴：本臂 N1”，不新增任意嘴学习造成的 XY转换复杂度。N1后续重标补偿不一定为零，所以学习仍要反算工艺高度。
- 料盘学习必须区分“相机 XY 学习”和“接触 Z 学习”：纯 XY 学习保留原工艺 Z，不再顺带写 0；需要学习接触 Z 时明确以 N1读数转换。
- 行学习、生成阵列、位置复制都只操作基准工艺坐标；不将某个嘴的已补偿轴目标保存到表中。
- 跨臂复制默认只转换可验证的 XY；Z保留目标臂已有值或标记需要示教。两臂 B 不能直接互相相减来推导工艺高度。
- 工装各模式保留实际用途。拍照位的 Z目前也被放料动作消费，UI应说明“拍照XY / 放料工艺Z”，不能误删其 Z。
- 工装参数区的立柱学习、定位和取料位置计算保留；只换算XY的按钮不能重算或清空已保存的工艺Z。
- 可增加紧凑的试动作嘴选择，用于验证 N2/N3，但不改变同臂共用工艺点位的数据维度。
- 料仓高度、盘层间距、料仓脱离高度保持原物理轴含义，不应用嘴补偿。

### E. 其他系统校准与视觉任务

- 九点/任务标定：仍按相机和任务组织。公共标定片由哪只基准嘴放置应在页上明确；不因选择相机2就隐式将公共放片切换为臂2。
- 两个 AffineCail：仍是两组相机转换，标定片放置/学习按指定基准嘴和对应 Z语义执行。
- 旋转中心：六嘴各自保存；页面选择写成“臂1/N1”等，内部沿用真实 XT配置ID，避免物理嘴序与历史ID混淆。
- 飞拍：保留原页入口，将两嘴偏差显示改为本臂三行；测量绑定实际参加本次任务的嘴，不能将“两片治具交换”当成“永远只有两只嘴”。仍保留原前/后排工站偏差。
- 识别模板和任务列表：验证第三嘴模组识别、空嘴识别及各调用名字一致；不靠补偿表替代视觉标定。
- 扫码姿态：原参数2的四嘴显示需要三嘴/臂覆盖，按选中嘴维护 U等参数，不与接触高度混存。
- 原“调试”页如保留向导，只连接这些真实页面、显示完成状态，不新增重复算法或配置。

## 五、新标定方法及与 UI 的数据约定

1. 每臂先人工示教三嘴到同一固定基准面的测量位置，使用各自规定的 U姿态。
2. 逐嘴回到其测量位置，其他嘴处于避让高度；低速接触检测、抬起、复测，记录各次实际 Z。
3. 按该 Z轴的接近方向 s（+1或−1）归一化：H=s×轴Z。重复性满足设定后计算平均值。
4. 首次本臂 B=H1，Δi=Hi−B。保存本臂基准、三嘴补偿及测量记录。
5. 重标固定 B不变：Δi_new=Hi_new−B。N1也适用此规则。更换基准面或轴坐标基准属于重新建立体系，需核对相关工艺高度，不能普通重标自动覆盖B。
6. 执行接触工艺：轴目标=s×(工艺Z+Δi)。示教：工艺Z=s×实际轴Z−Δi。补偿仅在明确的工艺/轴边界应用一次。
7. 轴回零位置、避让高度、相机纯XY位、料仓轴位和视觉误差不自动加入此补偿。

系统级保存：两臂固定 B、六嘴Δ、测量位置、方向关联、校准时间/版本等；不随产品切换。

产品级保存：供料/OK/NG盘、工站各工艺高度、每嘴各模式XY/角度偏差、产品识别模板；维持原分层。

目前三嘴项目的 `.draft.xml` 只是审核草稿，正式方案不能默认激活它。新正式标定应独立验证后明确生效，并记录其版本，避免草稿被生产加载。

## 六、推荐现场设置顺序

核对独立轴/IO映射和回零 → 人工示教基准面位置 → 六嘴Z标定 → 按实际依赖完成相机九点/坐标统一及六嘴旋转中心、飞拍 → 本臂N1示教各盘/工站工艺高度 → 六嘴逐嘴视觉取放偏差 → 在相同工艺高度下验证各嘴试动作。

以上是建议调试顺序，并非从旧代码中发现的已有完整向导。可保留经验证仍有效的相机参数，不要求仅因增加吸嘴就全部重做；新的嘴、轴和受机构变化影响的结果必须复核。

- 臂1/2数据隔离；六嘴选择、独立Z/U、IO、视觉模板一致；切产品不更改系统B/Δ。
- 所有学习、复制、阵列、试放/试取入口明确区分工艺Z和轴Z；不发生重复补偿；纯XY学习不覆盖Z。

- 本次仅交付基于源代码的评估与方案；本文不意味着上述页面已经适配完毕。
