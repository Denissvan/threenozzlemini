# 调试启用与夹具重复确认弹窗

## 用户确认的范围

1. 应用调试不应要求先屏蔽一个门禁。独立记录调试开启状态；未选择屏蔽项时仍检查全部原有急停、门禁及光箱。保留权限、运行期间禁止变更以及退出恢复逻辑。
2. 员工在第一臂吸料异常窗口人工置空夹具后，第二臂不得重复显示过期的吸料异常窗口。不是自动置空、也不修改首次启动时的料况初始化。

## 实现

- SafetyDebugMode 的原子状态增加独立开启位，掩码读取不变；界面移除空选择拦截并明确无屏蔽时按原配置检查。
- 三吸嘴夹具取料失败处理使用现有双臂弹窗锁，取得锁后重读当前穴位。仅 PICK_ERR、穴位已由员工置空、吸嘴记录为空且真实运行真空无料时返回 ConfirmedEmpty，跳过过期弹窗。停止、未知动作结果和记录/真空不一致继续原有处理。
- 正常取放料仍并行，不改首次启动全部穴位的状态，不改相机收图或飞拍偏移规则。

## 验证

真实取料恢复代码加并发边界测试：两臂先后进入窗口、员工置空两臂目标后只出现一次窗口；未置空的目标保持报警；吸嘴有料与停止不能被跳过。不加载控制器。

原有急停、门禁及真实 WinForms 界面测试验证无屏蔽开启与退出。使用 VS2022 MSBuild 全量编译到临时目录，现场仍需验收。
