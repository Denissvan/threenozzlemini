# 两模块独立运行与当次报警恢复

用户已明确四项行为：各模块不等对方预取；吸取/真空异常当次弹窗处理、重启仍异常再次弹窗、减少对账；无实际干涉不等待对方；已处理报警不在清料退出时再弹。

保留共享供料盘/成品盘资源锁、真实X避障预约、Z安全检查及转盘/夹具的双臂离场联锁。拆除业务上的双臂预取放行和末组卸料启动屏障。

协调器按臂保存任务阶段、源工站和提前预取目标。各臂仅等待并续接自己的任务，离开夹具后立即启动自己的尾部卸料及提前预取。下一工站可接管仍在料盘区的任务，入夹具只等本臂完成。共享工站闭合、转盘运动及最终清料仍检查两臂实际位置与全部任务结束。

吸取异常若物料身份尚未提交且真空异常，保留源穴记录，在当前弹窗要求员工处理并重新检查。未解决不允许继续或丢弃原穴。停止后保存当前异常；下一次启动先重新弹窗检查，再允许任何物理动作。真正的物料身份冲突、非吸取硬件异常仍保留故障保护。

报警使用单调代次标记。弹窗处理完成只确认本代次，不能清除另一线程后来写入的新报警；日志历史保留。

验证包含快慢臂独立放行、单臂尾部卸料、跨工站接管、停止续接不重复卸料、未处理真空禁止运动、问题再次出现再次弹窗、并发新报警保留，以及既有清料/避障回归和离线完整编译。无自动上机或部署。

需要同臂继续执行的夹具扫码、条码回检、计划中的光箱检查、合夹具后拍照/点检/霍尔流程，保留相应检查结束后的尾卸时机，避免同臂XY和相机被两个线程操作。光箱定时检查在本轮调度前快照，仅实际计划执行的检查延后卸料；普通启用但本轮不执行时不增加等待。各轮使用exchangeEpoch识别，同一WS对象再次上料不会沿用上一轮完成状态。
