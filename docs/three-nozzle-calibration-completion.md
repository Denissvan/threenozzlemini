# 三吸嘴标定补齐说明（2026-09-27）

## 已接入的界面与动作

- 系统设置 → 标定 → 吸嘴 Z 测高：两臂独立切换，测高与补偿、基准点设置、三次测量记录三个页签。
- 基准点设置：逐嘴学习机械 X/Y/U 和接近高度，人工填写探测终点；独立定位、停止定位、保存设置草稿。
- 测高：测量当前嘴或依次测量三嘴；每嘴三次真空接触，显示均值、极差、已存补偿、候选补偿；确认保存本臂才生效。
- 旋转中心：六嘴分别选择，调用选中嘴的独立 U 轴和对应旋转模板；三嘴飞拍表显示各嘴及前后排偏差/复测残差。
- 手动操作：每臂选择 N1/N2/N3 后 Z±、U±对应独立轴；原 U1/U2 保留固定映射。运行摘要显示三组 Z/U。
- 料盘/治具/视觉试动作/公共标定片的工艺 Z 示教与下降已接入正反转换；纯 XY 学习和跨臂 XY 复制不覆盖目标臂 Z。

## 测高使用顺序

1. 核实轴卡、方向、回零、软限位和六嘴空嘴；两臂分别使用各自固定基准面。相同基准面不意味着三嘴机械 XY 坐标相同。
2. 在基准点设置中选择嘴，手动定位至基准面上方，学习 XY/U/接近高度，设置大于接近高度的探测终点。高度统一为向下正值，实际轴正负由该嘴配置换算。
3. 核对探测速度、步距、极差上限。界面初始值只是软件默认值，实际位置及范围需要现场示教。
4. 首次先测 N1（或依次三嘴）。软件以 N1 三次接触均值建立本臂固定 B；不是把预设机械高度当作基准。N2、N3随后各测三次。
5. 核对重复性及候选补偿，保存本臂结果。另一臂独立执行同样流程。
6. 后续任意嘴重测均保持原 B，包括 N1；N1重测后补偿可以不为零。更改点位或探测参数会使对应候选记录失效，原正式补偿保持生效。
7. 正式测高完成后，用本臂 N1重新核对/示教料盘、夹具等工艺高度，再验证其他嘴取放。原双嘴工艺数据不能仅凭软件编译成功认定可直接使用。

## 数据与转换约定

正式文件为运行目录上一级 syscfg/NozzleZCalibration.xml，草稿为同目录 ThreeNozzleZCalibration.draft.xml。正式文件记录每臂固定 B、逐嘴点位、三次样本、方向、时间和探测参数，保存采用校验后替换并保留备份。旧草稿的手填 B/接触结果不会导入生产。

补偿 Δi = Hi - B；实际轴目标 = direction × (工艺高度 + Δi)。学习工艺高度时做反向换算。转换位置在上层工艺入口，XT.PickOrPlace/Place等底层仍接收实际轴坐标，防止重复补偿。供料盘、夹具取放、OK/NG落盘及对应试动作已覆盖；退回源穴使用原实际取料坐标。

回零/抬起0不加补偿。相机纯XY、旋转误差值、保存在z字段的料盘X均不当成工艺Z。马达扫码的逐嘴独立机械Z参数保持原有坐标语义。

未正式标定或方向与记录不一致会阻止工艺下降/自动启动。测量时的停止会请求停止本次登记的轴，输入读取错误终止探测，前置拒绝不会释放原有持料真空；未通过的候选不会替换正式结果。

## 验证与现场边界

离线模型/算法、真实运动适配器硬件桩、真实UI方法、三个测高页布局，以及旋转/飞拍实际partial硬件桩均有回归；现有三嘴专项回归12套通过。编译输出使用独立临时目录，不覆盖正在运行的软件。

离线预览数据仅为测试样例，未写入设备正式配置。未操作实际轴、未生成真实视觉模板、未启用硬件标定确认开关。现场仍需验证基准面密封、真空时延、重复性、六嘴U旋转模板/中心、取放高度、双臂避障和目标显示器DPI。

生产三嘴保持已有逐嘴定拍策略，新增三嘴飞拍标定不代表生产已经切换飞拍。实机校准及验收完成前，不能把本次离线通过当作设备已投产验证。

最终验证：Debug/x64整库MSBuild退出码0（存在既有警告）；csproj所有Compile源文件均存在；git diff --check通过。运动适配器15项、旋转/飞拍32项、旧三嘴专项12套通过；模型/示教/手动轴/真实测高页专项亦通过。模型和运动适配器测试使用PowerShell 7（pwsh），WinForms页面预览测试使用Windows PowerShell。
